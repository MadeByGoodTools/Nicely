# Nicely

A gentle note of encouragement, once a day.

Nicely opens one warm note the first time your browser starts each day. You can ask for another note or save a favourite. Everything stays in your browser; there is no account and no tracking.

## Install in Chrome, Edge, Firefox, Brave, or Arc

1. Unzip the Nicely folder.
2. Open your browser's extensions page.
3. Turn on **Developer mode**.
4. Choose **Load unpacked** and select the unzipped `Nicely` folder.

In Firefox, open `about:debugging`, choose **This Firefox**, then **Load Temporary Add-on** and select `manifest.json`.

Nicely opens immediately after installation, then only once: on the first browser start of each new local calendar day. After that, it stays quiet until tomorrow.

## Privacy

Nicely has no account, advertising, analytics, tracking, remote code, or external data collection. Saved notes and the last-opened date remain locally in your browser.

Read the full [Nicely privacy policy](https://goodtools.ca/privacy/nicely).
